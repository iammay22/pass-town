# 及格鎮

人生岔路口的小鎮篇。像素風的放置型校園 RPG，可以在校園裡走來走去、做主線和支線、加社團、打工、布置宿舍，離線時角色會自己幫你存錢。

線上玩：https://iammay22.github.io/pass-town/

## 怎麼玩

- 手機、平板請橫著拿：左手搖桿走路，右手 A 鍵互動
- 電腦：方向鍵或 WASD 走路，空白鍵或 E 互動，Tab 開手冊，M 開地圖

## 目前有的東西

- 場景：校園、圖書館、教學大樓、學務處、社團教室、便利商店、宿舍、學生餐廳、操場、校外夜市、考試中心
- 主線第一章「大一新生」、第二章「畢業門檻」（英檢）、六條支線、每天換新的三個每日任務
- 小遊戲：投籃、跑操場、套圈圈、上課抄筆記、英文單字與英檢
- 存檔放在瀏覽器裡，其他玩家目前是假的
