# 及格鎮

人生岔路口的小鎮篇。像素風的放置型校園 RPG，可以在校園裡走來走去、做主線和支線、加社團、打工、布置宿舍，離線時角色會自己幫你存錢。

線上玩：https://iammay22.github.io/pass-town/

## 樹洞留言牆的後端

用 Supabase。第一次要做三件事：

1. 在 Supabase 後台的 SQL Editor 執行 `supabase/schema.sql`
2. Authentication → Sign In / Providers 打開 Anonymous sign-ins
3. 把 Project Settings → API Keys 裡的 anon（publishable）key 貼到 `index.html` 的 `SB_KEY`

沒填 key 的時候，留言牆是示範版。

## 怎麼玩

- 手機、平板請橫著拿：左手搖桿走路，右手 A 鍵互動
- 電腦：方向鍵或 WASD 走路，空白鍵或 E 互動，Tab 開手冊，M 開地圖

## 目前有的東西

- 場景：校園、圖書館、教學大樓、學務處、社團教室、便利商店、宿舍、學生餐廳、操場、校外夜市、考試中心
- 主線第一章「大一新生」、第二章「畢業門檻」（英檢）、六條支線、每天換新的三個每日任務
- 小遊戲：投籃、跑操場、套圈圈、上課抄筆記、英文單字與英檢
- 升年級之間的劇情：阿芸的決定、社團成果發表、家裡的電話
- 放著也會進行的事：打工薪水、貓碗回禮、圖書館預約座位
- 存檔放在瀏覽器裡

## 後台

遊玩數據送到 Google 試算表「及格鎮｜數據後台」，由 `apps-script/Code.gs` 寫進 events 分頁，其他分頁都是公式。接法：在試算表的「擴充功能 > Apps Script」貼上 Code.gs，部署成網頁應用程式（執行身分選自己、所有人可存取），把網址貼到 index.html 的 `TRACK_URL`。之後改了 Code.gs 要在「管理部署作業」選新版本，網址才會用新程式。

樹洞留言和存款排行在 Supabase，資料表定義在 `supabase/schema.sql`。
